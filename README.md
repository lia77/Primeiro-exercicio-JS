# Meu Primeiro Programa! 👋

Este é o meu primeiro projeto de programação, feito como parte dos meus estudos em JavaScript. Um "Olá, mundo!" com um toque a mais: HTML, CSS e JavaScript trabalhando juntos.

## 📌 Sobre o projeto

A ideia era simples: criar uma página que exibisse uma mensagem de boas-vindas na tela e, além disso, disparasse um alerta usando JavaScript assim que a página fosse carregada. É o famoso "primeiro contato" com lógica de programação no navegador.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização (cor de fundo, fonte e cor do texto)
- **JavaScript** — interatividade (janela de alerta)

## ✨ Funcionalidades

- Exibe um título de boas-vindas (`Olá, mundo!`)
- Exibe um parágrafo com uma mensagem pessoal
- Dispara uma janela de alerta (`alert`) com uma mensagem assim que a página é aberta
- Fundo colorido e tipografia customizada via CSS

## 🚀 Como executar

1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` em qualquer navegador
3. Pronto! A mensagem aparece na tela e o alerta é disparado automaticamente

Não é necessário instalar nada — é só HTML, CSS e JS puros, sem dependências.

## 🧠 O que eu aprendi

- Estrutura básica de um documento HTML (`<head>`, `<body>`, etc.)
- Como aplicar estilos simples com CSS diretamente no `<head>`
- Como inserir e executar um script JavaScript dentro do HTML
- Uso da função `window.alert()` para exibir mensagens ao usuário
